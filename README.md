# Python Projects

A collection of small Python projects, built for practice and learning core programming concepts.

## Projects

- **Calculator** — A simple command-line calculator that performs basic arithmetic operations.
- **Guess the Number** — A number-guessing game where the player tries to guess a randomly generated number.
- **Password Generator** — Generates strong, random passwords based on user-defined criteria.
- **Rock Paper Scissors** — The classic game playable against the computer.
- **File Management System** — A tool to create, read, update, delete, and list files.
